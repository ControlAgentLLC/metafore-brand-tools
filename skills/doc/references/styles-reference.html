07 · How to mark this up

Hand me back the changes you want.

Reference any element by its ID (A1, A2, B1, B2, C1–C9). Examples:

  • A1 cover H1 — bump to 50pt
  • A2 TOC — drop the level-2 entries, only show top-level sections
  • B2 footer — change color from ink-4 to ink-3 (less faint)
  • C2 H2 — go to 28pt
  • C4 body — line spacing to 16pt
  • C6 bullets — switch glyph from • to ›, color them teal
  • C7 callout — drop the left border, use a 1pt full outline in line-strong instead
  • C8 table — alternate row shading in bg-solid #F8FAFA
