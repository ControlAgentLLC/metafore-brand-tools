Universal invariants

Type floors (marketing 2026)

RoleSize
Body32px
Labels, eyebrows, section label24px
Secondary card / tile text22–24px
Footer22px
Anything essential≥ 22px
Content titles / cover / closing56–64 / 112 / 88px

Overflow? Widen the well or cut words. Shrinking type is never the fix.

Palette — one accent family

004D50006B6F03565788DCE067A4A4E8F4F5F8FAFA1A1A1A
  • White-first canvas; solid fills; no gradients or shadows
  • Retired, never used: the old mid teal and the old cyan
  • Status colors for state only

Type roles

  • Geist 400 for headers only — never bold or italic; size carries weight
  • Inter for body
  • IBM Plex Mono uppercase for labels (never tracked or bold in PPTX)
  • Two-tone hero: ink + logo-dark; titles fit two lines

Density & visuals

  • No paragraph over three lines
  • 3+ parallel facts become bullets
  • Every slide carries a visual — library icon first
  • A graphic must explain the headline; real numbers only

Layout

  • Flex / grid with gaps — never absolute offsets for text
  • ≥ 48px between title and body
  • Chrome: section label TL, icon 72×60 TR, footer at 36px
  • Wordmark on the cover only; light on light, dark on dark

Rhythm & content

  • No pattern more than twice per deck
  • Never trim content to fit a pattern — re-pattern or split
  • Tile eyebrows all the same --teal
  • No negation pivots, rhetorical triplets, “leverage”, “disrupt”, comfort words

Composing a deck

The MetaWorks corporate deck is the reference sequence — deviate on purpose, not by accident. Short decks drop the agenda, company, integrations, and timeline; 20+ slide decks add dividers and may use one pull quote.

P-01 Cover → P-03 Agenda → P-04 Company → P-05 Problem → P-06 Four graphs (Meta → Knowledge → Context → Control) → P-05 Suite intro → P-08 Modules → P-07 Platform → P-10 Integrations → P-09 KPI band → P-05 Why → P-18 In action ×1–3 → P-21 Vertical anchor (optional) → P-11 Deployment → P-13 Closing
