# P-20 · Wide data table

**When:** a mapping best read as rows ("what we deliver": capability / module / description). 4–6 rows, 2–3 columns. **Tier:** `hybrid`.

```html
<section class="slide p-table" data-pptx="hybrid" data-pattern="P-20">
  <div class="section-label">What MetaWorks delivers</div>
  <!-- @logo:icon-light width="72" height="60" class="icon-tr" -->
  <div class="head"><h2>Every capability, mapped to its <span class="accent">module</span></h2></div>
  <div class="table" data-visual style="--table-cols: 1fr 0.8fr 2fr">
    <div class="th">Capability</div><div class="th">Module</div><div class="th">What it does</div>
    <div class="cap">Live operating view</div><div class="mod">Focus</div><div class="desc">A role-scoped Pulse for every leader.</div>
    <!-- 4–6 rows -->
  </div>
  <!-- @footer -->
</section>
```

- Description cells ≤ 2 lines. Header row gets the strong ink rule; data rows get hairlines; no vertical dividers.
- If the title wraps past two lines, shorten it — don't shrink it.
